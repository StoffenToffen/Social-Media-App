# Busy Bee - Social Media App

<img width="1893" height="1181" alt="image" src="https://github.com/user-attachments/assets/33d1e24a-773b-4144-a410-512f931546f8" />

Developed a full-stack social media app with features like post, post feeds, likes, modals, and authentication, using Firebase for database management.

## Install Packages
```bash
npm i
```

## Setup .env file

```bash
NEXT_PUBLIC_API_KEY=
NEXT_PUBLIC_AUTH_DOMAIN=
NEXT_PUBLIC_PROJECT_ID=
NEXT_PUBLIC_STORAGE_BUCKET=
NEXT_PUBLIC_MESSAGING_SENDER_ID=
NEXT_PUBLIC_APP_ID=
```

## Start the app

```bash
npm run dev
```
